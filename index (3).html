About

A Full Website Without a Server Bill

This project combines three free Google and GitHub services into one fully functional product. GitHub Pages serves the static website worldwide over HTTPS, while a Google Apps Script deployment works as the backend API endpoint.

When a visitor submits the contact form, the browser sends the data to your Apps Script Web App, which validates it and stores it in a Google Sheet that only you can see. The whole pipeline takes milliseconds and requires no servers to maintain, no SSL certificates to renew and no hosting fees to pay.

  • Deploy in under 10 minutes by copying and pasting
  • Unlimited visitors on GitHub Pages hosting
  • Every submission stored safely in your own Google account
  • Easy to customize — every section is clearly commented
